HyperbolicTextCompressor • Semantic compression prototype

What this project does

It explores semantic “compression” of text by embedding words in the Poincaré disk (hyperbolic space), measuring hyperbolic distances, and clustering similar words. The size of clusters and their representatives give a toy estimate of compression savings.

Inputs

  • Plain text (UTF‑8)
  • Config: windowSize, projection, weighting, clusterThreshold
  • Dimensions and vocabulary cap (dimension(s), maxVocab)
  • Normalization toggle (normalize)
  • Seed for reproducibility
tokens embeddings clusters

Core idea

Use hyperbolic geometry (negative curvature) to represent hierarchical/semantic structure. Cluster by hyperbolic distance to identify groups of near‑synonymous terms, then encode each group via a representative + dictionary.

Poincaré disk

Outputs

Quick start

# Run demo
node .\compressionTest.js

# Benchmark & report (PowerShell)
# Single-line:
npm run bench -- --file .\samples\sample.txt --auto --autoMethod hybrid --k 0,10 --approxKNN 1 --approxKCandidates 100 --emitClusters .\out\clusters --outJson .\out\bench.jsonl

# Multi-line with PowerShell line continuation (`):
npm run bench -- --file .\samples\sample.txt --auto --autoMethod hybrid `
  --k 0,10 --approxKNN 1 --approxKCandidates 100 `
  --emitClusters .\out\clusters --outJson .\out\bench.jsonl

# Generate HTML report
npm run report  # writes .\out\report.html

Interpreting results

  • Compression ratio: estimated size after clustering vs. original
  • Savings: percentage reduction suggested by cluster mapping
  • Clusters: representative term + members

Note: this is a research prototype, not a general‑purpose compressor.

Minimal usage (API)

const HyperbolicTextCompressor = require('./compressionTest');
const c = new HyperbolicTextCompressor(2, {
  maxVocab: 3000,
  seed: 42,
  windowSize: 3,
  clusterThreshold: 0.4,
  projection: 'random',           // 'random' | 'firstD' | 'svd'
  weighting: 'distance',          // 'uniform' | 'distance'
  autoThreshold: true,            // optional auto tuning
  autoThresholdMethod: 'hybrid'   // 'percentile' | 'mad' | 'hybrid'
});
const res = c.analyzeAndCompress('your text here');
console.log(res.compressionRatio, res.semanticClusters.slice(0,3));
