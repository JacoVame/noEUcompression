# 🇬🇧 HyperbolicTextCompressor — English documentation

> A research prototype that "compresses" text not by shortening binary codes, but by gathering words into semantic families inside a curved space: the Poincaré disk.
>
> It is not a real file compressor. It is an experiment to see whether hyperbolic geometry can capture the redundancy of language better than the flat space we are used to.
