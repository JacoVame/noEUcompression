When AI Becomes a Multiplier for Theoretical Research

This report consolidates the narrative and the technical analysis of an exploratory prototype that compresses text using hyperbolic geometry (Poincaré disk). The goal is not to replace theoretical work with automation, but to amplify it—rapidly iterating on ideas, implementing complex pipelines, and producing diagnostics and benchmarks.

Core Idea

Use non‑Euclidean geometry—specifically the hyperbolic plane—to model deep semantic structure so that words “close in meaning” lie close in the Poincaré disk, enabling geometry‑driven clustering and compression.

AI as Force Multiplier

AI accelerates exploration: testing multiple projections, implementing algorithms fast, and generating visual explanations—while keeping human judgment in the loop.

Status

Working prototype with auto‑thresholds (percentile/MAD/hybrid), optional k‑NN prefilter, benchmarking harness emitting JSONL, and an HTML reporting tool. Validation versus standard compressors remains future work.

Compression Pipeline

  1. 1) Preprocessing

    Unicode‑aware tokenization with optional NFKC normalization for consistency across equivalent characters.

  2. 2) Co‑occurrence Analysis

    Build a sparse co‑occurrence matrix with a sliding window; weights can be uniform or decay with distance.

  3. 3) Projection

    Choose among random, firstD (first components), or svd (for small vocabularies) before mapping to hyperbolic space.

  4. 4) Hyperbolic Embedding

    Map points into the Poincaré disk to reflect semantic distances. Distances are measured via the hyperbolic metric.

  5. 5) Semantic Clustering

    Union–find merges pairs under a threshold on Poincaré distances. An optional Euclidean k‑NN prefilter reduces pair checks from O(V²) to ~O(V·K). Approximate prefilter is available.

  6. 6) Auto‑Threshold + Diagnostics

    Automatically set thresholds via percentile, MAD, or hybrid, and record summary stats (median, MAD, sigma≈1.4826·MAD, p95, chosen method, sample size).

  7. 7) Encode

    Represent clusters by a central word (representative). Encode the sequence of representatives plus a decoding table.

Poincaré Disk (intuition)

A “curved world” inside a circle: near the center space looks roomy; near the boundary it stretches. Shortest paths are arcs. Great for hierarchies—place the root at the center, branches fan out naturally; similar items stay near, very different ones move far apart.

Deep Structure Example

“Maria gave Luca a book yesterday.” → agent = Maria; action = give; object = book; recipient = Luca; time = yesterday. Rewordings preserve this structure and should remain close in the embedding.

Mathematical Foundations

Poincaré Disk

D = { z ∈ ℂ : |z| < 1 }

                    
Hyperbolic Distance

                    
d_H(u, v) = arccosh(1 + 2||u - v||² / ((1 - ||u||²)(1 - ||v||²)))

Euclidean → Poincaré Mapping (prototype)

x_poincaré = x · min(0.9/||x||, 1)

This simple scaling keeps points inside the disk for visualization and clustering in the prototype.

Prototype Options and Parameters

Projection / Embedding

  • projection: 'random' | 'firstD' | 'svd' (SVD for small vocabularies)
  • dimension: hyperbolic space dimensionality (default 2)
  • normalize: optional NFKC normalization for tokens
  • svdMaxN: limit for enabling SVD path

Co‑occurrence

  • windowSize: sliding window width
  • weighting: 'uniform' or 'distance' decay
  • maxVocab: cap vocabulary size (optional)

Clustering

  • Union–find on hyperbolic distance with threshold
  • clusterK: Euclidean k‑NN prefilter (0 disables)
  • approxKNN and approxKCandidates: sampling‑based approximate prefilter

Auto‑Threshold & Diagnostics

  • autoThreshold: enable automatic thresholding
  • autoThresholdMethod: 'percentile' | 'mad' | 'hybrid'
  • autoThresholdPercentile, autoThresholdMADK
  • autoStats: emit median, MAD, sigma, p95, chosen method, sample size
  • histBins: histogram bins for sampled distances

How to Run

Quick demo

npm run demo

Embedded smoke tests

$env:HTC_RUN_TESTS='1'; node .\compressionTest.js; Remove-Item Env:HTC_RUN_TESTS

Benchmark a file (hybrid auto‑threshold + diagnostics)

npm run bench -- --file .\sample.txt --auto --autoMethod hybrid --autoStats

The benchmark emits JSONL lines with run statistics and (if requested) threshold diagnostics suitable for reporting.

Reporting and Visualizations

A reporting script reads the JSONL output from the benchmark and creates an HTML report with summary tables and charts. It can show: best savings% per input, number of clusters, savings% by K and projection, and distance histograms if --autoStats and --histBins are used.

Generate report

npm run report

Output is typically written to out/report.html.

Limitations and Future Work

Current Limitations

  • Computational overhead of hyperbolic distance
  • Threshold sensitivity and choice of dimensionality
  • Short texts may not benefit despite overhead
  • Limited validation on large corpora

Planned Improvements

  • Faster distance computations and incremental clustering
  • Parallelization of embedding computations
  • Automatic dimensionality and window selection

Empirical Validation

  • Compare with gzip, bzip2, xz on standard corpora
  • Analyze performance/quality trade‑offs
  • Report absolute ratios and timings
