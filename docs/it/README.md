# 🇮🇹 HyperbolicTextCompressor — Documentazione in italiano

> Un prototipo di ricerca che prova a «comprimere» il testo non con codici binari più corti, ma raggruppando le parole in famiglie semantiche dentro uno spazio curvo: il disco di Poincaré.
>
> Non è un compressore di file vero e proprio: è un esperimento per capire se la geometria iperbolica può catturare la ridondanza del linguaggio meglio dello spazio piatto a cui siamo abituati.
